# SIGNATE 練習問題（タイタニック生存予測）

## 概要
データ分析の基本フロー（EDA・前処理・モデル学習・予測・提出）と仮説検証のプロセスを習得するために取り組んだ記録です。

## 試行錯誤とスコアの推移
1. **ベースライン（基礎編）**: スコア `（0.7087515）`
2. **`pclass` を追加**: スコア `（0.6988120271412778）`
   - 考察：pclassとfareはともに強い相関があるため予測のバランスが崩れる。
3. **`sex` を数値化して追加し、欠損値を補完**: スコア `（0.8204491751392833）`
   - 考察：生存率への影響が大きい性別情報を加えたことで予測が変化した。
4. **`age` の欠損値を中央値で補完して追加**: スコア `（0.8331851980316071）`
   - 考察：欠損値を中央値に変換することで、モデルが分析しやすいと感じた。

## 学んだこと
- 一度に複数の変更を加えず、1変数ずつ仮説検証を行う重要性
- 欠損値の確認と補完手法の基礎
